Справочник информации F.A.Q.

  1. Поиск, фильтрация и настройка отображения информации. Для поиска конкретной номенклатуры — поисковая строка (артикул, штрихкод, наименование). Показать все →
  1. Создание новой номенклатуры. Одной — кнопка «+ Создать» на верхней панели; массовой — кнопка «Импорт».
  2. Редактирование номенклатуры. Выбрать строку → правая кнопка мыши → «Редактировать». Также доступно в карточке товара (кнопка «Изменить»). Клик по артикулу открывает товарный запас снизу; выбор чек-боксов — массовое редактирование и печать ШК/этикеток.
  3. Права. Значения по умолчанию в форме создания задаются на уровне интерфейса и только Админом.

Штрихкод EAN-13 — термопринтер

Вверху — артикул, далее — наименование, внизу — EAN-13. Один макет, размер этикетки выбирается ниже. Два тракта: HTML — печать из браузера (термо через драйвер или обычный принтер), ZPL — файл для Zebra-совместимых термопринтеров.
В диалоге печати выбери термопринтер и тот же размер (58×40). Поля без масштабирования, размер страницы — из этикетки.
