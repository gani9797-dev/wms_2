📥 Загрузить приход

Форматы (как у робота in/out): CSV/TXT (разделитель «;», UTF-8, первая строка — заголовок) или Excel-заявка .xlsx/.xlsm («Заявка на приемку»: шапка с номером заказа/датой/поставщиком + таблица груза).
CSV колонки: Поставщик;артикул;наименование;количество;качество;штрихкод;группа[;дата_производства;партия]
Обязательные: поставщик (нового добавим в справочник), артикул, наименование, количество. Качество по умолчанию «Годен», штрихкод по умолчанию = артикул.
Excel-заявка: таблицу ищем гибко по заголовку «Артикул» + «Количество»; колонка «Партия» сохраняется как партия поставщика. Номер заказа → внешний №, ожидаемая дата прибытия ТС → план, поставщик из шапки.
Пример CSV: MK-ASM-1315;Мяч баскетбольный А;10;Годен;2178899952100,4673192631679;Спорттовары;2025-06-01;202607052
Будет создан документ поступления. Новые артикулы, штрихкоды и группы попадут в номенклатуру (штрихкоды копятся), новые товары потребуют обмеров на ТСД. Группа в приходе и на ТСД не показывается; если группа «Легкая промышленность» — на ТСД потребуется сканирование Честного знака.

📤 Загрузить расход

Форматы (как у робота in/out): CSV/TXT (разделитель «;», UTF-8, первая строка — заголовок) или Excel-заявка .xlsx/.xlsm («Заявка на отгрузку»: шапка с номером заказа/датой/получателем + таблица груза).
CSV колонки: Контрагент;Получатель;Тип отгрузки;артикул;количество;дата_производства;Признак сканирования марки;Признак сканирования с/н;Комментарий
Плоская таблица: Контрагент;артикул;наименование;количество;ед. изм.;партия;дата_производства — лишние колонки можно просто добавить, шапка ищется сама.
Обязательные: контрагент (нового добавим в справочник контрагентов), артикул, количество.
Необязательные: получатель, тип отгрузки, наименование, единица измерения, партия, дата производства (ГГГГ-ММ-ДД или ДД.ММ.ГГГГ), признаки сканирования (да/нет), комментарий.
Excel-заявка: таблицу ищем гибко по заголовку «Артикул» + «Количество»; номер заказа → в комментарий наряда, дата отгрузки → план отгрузки, получатель и тип отгрузки → из шапки.
Пример CSV: ООО «СпортОпт»;ПЭК;Доставка;MK-ASM-1315;5;01.06.2025;да;нет;Срочно
Будет создан наряд с внутренним номером or_XXXXXX (один файл = один наряд), а отгрузка по нему сформируется автоматически.

🏷 Загрузить марки ЧЗ

Формат файла: CSV, разделитель «;», кодировка UTF-8, первая строка — заголовок.
Колонки: артикул;марка (обе обязательные).
Пример: MK-ASM-1315;0104640288927222215-Uy?Kp5C(_hHlhUqHGG
Марки сверяются с позициями документа: чужой артикул отклоняется построчно. На ТСД сканированные марки сверяются с этим реестром: нет в системе или чужая — ошибка.
