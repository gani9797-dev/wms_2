# WMS TiMLog

Складская система (WMS) на PHP + PostgreSQL: приёмка, размещение, ячейки, заказы,
отгрузка, упаковка, ТСД, этикетки (термо/PDF), товарный запас, журнал, биллинги,
наблюдения, настройки и роли. Есть REST API для интеграции с ERP/1С/TMS/маркетплейсами.

## Быстрый старт

```bash
cp .env.example .env      # укажите PG_HOST/PG_DB/PG_USER/PG_PASSWORD и TSD_TOKEN
php -S 0.0.0.0:8001 -t . router.php
```

- Портал: <http://127.0.0.1:8001> (вход — `/login`, по `employees.login`/`password_hash`).
- БД: PostgreSQL (по умолчанию `WMS_DB_DRIVER=pgsql`), схема — [`db/schema-pg.sql`](db/schema-pg.sql).
- Секреты (`.env`, БД) в git не коммитятся.

## Интеграция с ERP и другими системами

- Руководство (настройка WMS и ERP, примеры, вебхуки, приёмка):
  [`документация/ИНТЕГРАЦИЯ-API-ERP.md`](документация/ИНТЕГРАЦИЯ-API-ERP.md)
- Контракт: [`api/v1/openapi.yaml`](api/v1/openapi.yaml) (OpenAPI 3.1).
- Настройки и журналы: **13 Настройки → Интеграция и логирование**
  (токены, rate limit, callback URL, HMAC, журнал API, outbox вебхуков, алерты).
- Возможности: OAuth 2.0 client_credentials (JWT ≤ 60 мин), идемпотентность по
  `external_id`/`sku`, пагинация, единый формат ошибок, rate limit с `Retry-After`,
  вебхуки `order.status` с HMAC-SHA256 и повторами 1/5/30 минут.
